I am further developing a 120 minute hands-on workshop. The workshop is our first resource that is being published with complete documentation in the format of Open Educational Resources.\
\
While the iteration of this workshop is from the view of of a learner that takes this workshop, the target audience are educators in the space of data stewardship, research software engineering, data science, and related, as the workshop provides the foundation of working with Git and GitHub in an applied project-based way with focus on collaboration. \
\
The software stack that is expected for participants to be comfortable with is:\
\
For this course, we assume that you have some prior knowledge of R and RStudio. You should be able to:

- install and load R packages

- read and run short R scripts

- edit and run R Markdown / Quarto documents

- navigate the RStudio IDE

- identify the four panes of the RStudio IDE (Script, Environment, Files, Console)

A week prior to the workshop, participants will received detailed instructtions to work through, so that the correct software environment is available during the workshop. As an approach, this is different from the more typical Posit Cloud environment I use for complete novices. This workshop is designed for those that have worked with software before, but hjave not had a solid, applied introduction.

The goal of the workshop is to learn from other educators about the insurtcutional design and receive feedback whether the workshop wopuld also be applicable to be taught by themselves. Thsi would grant a follow-up workshop in which educators are taught the workflows of using this OER for their own needs and setting up infrastructure to be able to teach it.
